# iPad Clone Coding

Apple의 iPad 10.2 웹페이지를 따라 만들어보며  
HTML, CSS, JavaScript를 연습한 프로젝트입니다.

강의를 들으면서 웹페이지의 구조를 만들고,  
반응형 레이아웃과 JavaScript 동작을 구현해보았습니다.

배포 링크
https://ipad-six-eta.vercel.app/

## Tech Stack

- HTML
- CSS
- JavaScript

## 구현 내용

- 반응형 웹 레이아웃
- 데스크톱 / 모바일 헤더
- 검색창 및 메뉴 동작
- 장바구니 메뉴
- 스크롤 애니메이션
- 비디오 재생 / 정지
- JavaScript 데이터를 이용한 iPad 제품 렌더링

## Project Structure

```text
ipad
├── css
│   └── main.css
├── data
├── images
├── js
│   └── main.js
├── videos
└── index.html
```

## 공부 내용

- HTML 페이지 구조 작성
- CSS 레이아웃 및 반응형 웹
- Media Query
- DOM 조작
- 이벤트 처리
- JavaScript Module
- Intersection Observer
- JavaScript를 이용한 동적 렌더링
